How Macros Work

Macros are like functions in templates. Define once, use anywhere:

{# Define in macros.html #}
{%- raw %}
{% macro alert(message, type='info') %}
    <div class="alert-{{ type }}">{{ message }}</div>
{% endmacro %}

{# Use in any template #}
{% from "macros.html" import alert %}
{{ alert("Hello!", "success") }}
{% endraw %}
