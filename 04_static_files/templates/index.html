How Static Files Work

Flask serves files from the static/ folder at the URL /static/.

Referencing Static Files

<!-- CSS -->
<link rel="stylesheet" href="{{ '{{ url_for(\'static\', filename=\'style.css\') }}' }}">

<!-- JavaScript -->
<script src="{{ '{{ url_for(\'static\', filename=\'js/app.js\') }}' }}"></script>

<!-- Images -->
<img src="{{ '{{ url_for(\'static\', filename=\'images/logo.png\') }}' }}" alt="Logo">

Why use url_for('static', ...)?

  • Works regardless of where the app is mounted
  • Handles URL escaping automatically
  • Easy to change the static folder path later
  • Blueprint-aware for modular apps

This page uses:

{{ url_for('static', filename='style.css') }}

The CSS file adds the gradient background, card styles, and typography you see on this page.
